================================================================================
EXPERIMENT 11: FAMILIARIZING ROUTER COMMANDS - CLI CHEAT SHEET
================================================================================

1. ROUTER MODES:
----------------
Router> enable                         ! Enter Privileged EXEC mode
Router# disable                        ! Exit back to User EXEC mode
Router# configure terminal             ! Enter Global Configuration mode
Router(config)# exit                   ! Exit back to Privileged EXEC mode
Router# exit                           ! Close console connection

2. SYSTEM INSPECTION & SHOW COMMANDS:
--------------------------------------
Router# show version                   ! View OS version, hardware model, uptime, RAM/Flash/NVRAM
Router# show ip protocols              ! View active routing protocols
Router# show ip route                  ! Display routing table
Router# show ip interface brief        ! Table of all interfaces, IPs, status, protocol
Router# show interfaces FastEthernet0/0! Detailed Layer 1/2 statistics for interface
Router# show controllers serial 0/0/0  ! Check DTE vs DCE controller and clock rate
Router# show history                   ! View circular command history buffer
Router# terminal history size 50       ! Increase history buffer size
Router# show clock                     ! View software clock
Router# clock set 10:30:00 11 Oct 2026 ! Set software clock
Router# show hosts                     ! View DNS cache and static host entries

3. SAVING CONFIGURATIONS:
-------------------------
Router# copy running-config startup-config  ! Save RAM config to NVRAM
Router# write memory                        ! Short equivalent

4. CONFIGURING ETHERNET & SERIAL INTERFACES:
--------------------------------------------
! Router 1 (DCE Side)
Router> enable
Router# configure terminal
Router(config)# hostname Router1
Router1(config)# interface FastEthernet0/0
Router1(config-if)# ip address 172.16.10.1 255.255.255.0
Router1(config-if)# no shutdown
Router1(config-if)# exit
Router1(config)# interface Serial0/0/0
Router1(config-if)# ip address 172.16.20.1 255.255.255.0
Router1(config-if)# clock rate 64000
Router1(config-if)# no shutdown
Router1(config-if)# end
Router1# copy running-config startup-config

! Router 2 (DTE Side)
Router> enable
Router# configure terminal
Router(config)# hostname Router2
Router2(config)# interface Serial0/0/0
Router2(config-if)# ip address 172.16.20.2 255.255.255.0
Router2(config-if)# no shutdown
Router2(config-if)# end
Router2# copy running-config startup-config
